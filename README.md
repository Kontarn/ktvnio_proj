# Система Дистанционного Обучения

Веб-приложение для дистанционного обучения на примере решения квадратных уравнений.

## Описание

Система включает в себя следующие функциональные блоки:

1. **Блок аутентификации** — вход в систему с учётом ролей пользователей
2. **Блок записи на курс** — возможность записаться на курс обучения
3. **Модуль изучения материала** — изучение теории и примеров решения квадратных уравнений
4. **Модуль тестирования** — тестовые вопросы для проверки знаний
5. **Журнал событий** — протокол всех действий участников системы

## Роли пользователей

- **Слушатель** — может записываться на курсы, изучать материал и проходить тесты
- **Преподаватель** — имеет доступ ко всем функциям + просмотр пользователей и журналов
- **Разработчик** — имеет доступ ко всем функциям + просмотр пользователей и журналов
- **Техническая поддержка** — имеет доступ ко всем функциям + просмотр пользователей и журналов

## Запуск

### Способ 1: Открыть напрямую
1. Откройте файл `index.html` в браузере

### Способ 2: Локальный сервер (рекомендуется)
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js (нужен http-server)
npx http-server -p 8000
```

Затем откройте http://localhost:8000

## Функциональность

### Аутентификация
- Вход/выход из системы
- Сохранение сессии
- Логирование времени входа/выхода

### Курсы
- Просмотр доступных курсов
- Запись на курс
- Отслеживание статуса записи

### Изучение материала
- 5 тем по решению квадратных уравнений:
  1. Введение в квадратные уравнения
  2. Дискриминант квадратного уравнения
  3. Примеры решения
  4. Теорема Виета
  5. Практические задачи
- Навигация по темам
- Отслеживание прогресса

### Тестирование
- 10 вопросов по теме
- Таймер (30 минут)
- Мгновенная проверка результатов
- Сохранение результатов

### Журнал событий
- Фильтрация по пользователю
- Фильтрация по типу события
- Все действия записываются:
  - Вход/выход из системы
  - Запись на курс
  - Изучение материала
  - Прохождение тестов

## Хранение данных

Приложение использует `localStorage` браузера для сохранения:
- Регистрации пользователей
- Прогресса обучения
- Результатов тестов
- Журнала событий

Данные также загружаются из `data.json` при первом запуске.
