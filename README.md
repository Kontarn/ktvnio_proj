# Система Дистанционного Обучения

Веб-приложение для дистанционного обучения на примере решения квадратных уравнений.

## Описание

Система включает в себя следующие функциональные блоки:

1. **Блок аутентификации** — вход в систему с учётом ролей пользователей
2. **Блок записи на курс** — возможность записаться на курс обучения
3. **Модуль изучения материала** — изучение теории и примеров решения квадратных уравнений
4. **Модуль тестирования** — тестовые вопросы для проверки знаний
5. **Журнал событий** — протокол всех действий участников системы

## Роли пользователей

- **Слушатель** — может записываться на курсы, изучать материал и проходить тесты
- **Преподаватель** — имеет доступ ко всем функциям + просмотр пользователей и журналов
- **Разработчик** — имеет доступ ко всем функциям + просмотр пользователей и журналов
- **Техническая поддержка** — имеет доступ ко всем функциям + просмотр пользователей и журналов

## Системные требования

- **Node.js** версии 14.0.0 или выше
- **npm** версии 6.0.0 или выше
- Современный браузер с поддержкой ES6+ (Chrome, Firefox, Edge, Safari)

## Зависимости

Проект использует следующие npm-пакеты (указаны в `package.json`):

```json
{
  "express": "^4.18.2",      # Веб-фреймворк для Node.js
  "cors": "^2.8.5",          # Поддержка CORS
  "bcryptjs": "^2.4.3",      # Хеширование паролей
  "better-sqlite3": "^9.2.2" # SQLite драйвер для Node.js
}
```

**nodemon** — утилита для автоматической перезагрузки сервера при разработке (devDependencies)

## Установка и запуск

### 1. Клонировать репозиторий
```bash
git clone https://github.com/ваш-username/ваш-репозиторий.git
cd ваш-репозиторий
```

### 2. Установить зависимости
```bash
npm install
```

### 3. Запустить сервер
```bash
npm start
```

Или в фоновом режиме:
```bash
npm start &
```

Сервер запустится на **http://localhost:3000**

### 4. Открыть в браузере
Откройте **http://localhost:3000** в любом современном браузере

## Функциональность

### Аутентификация
- Вход/выход из системы
- Сохранение сессии
- Логирование времени входа/выхода

### Курсы
- Просмотр доступных курсов
- Запись на курс
- Отслеживание статуса записи

### Изучение материала
- 5 тем по решению квадратных уравнений:
  1. Введение в квадратные уравнения
  2. Дискриминант квадратного уравнения
  3. Примеры решения
  4. Теорема Виета
  5. Практические задачи
- Навигация по темам
- Отслеживание прогресса

### Тестирование
- 10 вопросов по теме
- Таймер (30 минут)
- Мгновенная проверка результатов
- Сохранение результатов

### Журнал событий
- Фильтрация по пользователю
- Фильтрация по типу события
- Все действия записываются:
  - Вход/выход из системы
  - Запись на курс
  - Изучение материала
  - Прохождение тестов

## Хранение данных

Приложение использует:
- **SQLite (school.db)** — основная база данных для хранения:
  - Пользователей и их паролей (хешированных)
  - Курсов, тем и тестов
  - Прогресса обучения (learningProgress)
  - Результатов тестов (testResults)
  - Журнала событий (activity_logs)

- **LocalStorage** — только для хранения текущей сессии пользователя (авторизация)

## Технологии

- **Backend**: Node.js + Express
- **Database**: SQLite (better-sqlite3)
- **Frontend**: Vanilla JavaScript (ES6+), HTML5, CSS3
- **Authentication**: bcryptjs для хеширования паролей
- **Session**: LocalStorage для хранения сессии пользователя

## GitHub Pages

Для публикации статической версии проекта:

1. Папка `docs/` содержит копию файлов из `public/`
2. В настройках репозитория включите GitHub Pages:
   - **Settings → Pages**
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`
   - **Folder**: `/docs`

**Важно:** На GitHub Pages работает только фронтенд. API и база данных не доступны, так как GitHub Pages — статический хостинг без Node.js.

## Разработка

### Запуск в режиме разработки
```bash
npm start
```

Сервер автоматически создаст базу данных `school.db` при первом запуске.

### Пересоздание базы данных
Если нужно сбросить все данные:
```bash
rm school.db
npm start
```
